# Информационная система гостиницы «Элеон»

Курсовой проект по дисциплине **«Проектирование информационных систем и баз данных»** (ОмГУПС, кафедра «Автоматика и системы управления»).

Система предназначена для автоматизации основных бизнес-процессов гостиничного предприятия: учёта номерного фонда, предварительного бронирования, заселения и выселения постояльцев, регистрации дополнительных услуг, финансовых расчётов, ведения табельного учёта и начисления заработной платы персоналу.

---

## Стек технологий
* **СУБД:** PostgreSQL 16 (13 нормализованных таблиц в 3НФ, составные B-tree индексы, представления `VIEW` и хранимые функции `PL/pgSQL`)
* **Backend:** Python 3.12, микрофреймворк **Flask**, драйвер **psycopg2**
* **Frontend:** HTML5, CSS3, JavaScript (Fetch API)

---

## Структура проекта

```text
hotel-eleon-db/
├── app.py                     # Серверное приложение на Flask (маршруты, API, ролевой доступ)
├── schema.sql                 # DDL-скрипт создания таблиц, ограничений и индексов PostgreSQL
├── seed.sql                   # DML-скрипт наполнения базы данных тестовыми данными
├── views_and_functions.sql    # Представления (VIEW) и хранимые функции (PL/pgSQL)
└── templates/                 # HTML-шаблоны пользовательского интерфейса
```

---

## Роли пользователей и тестовый доступ

В приложении реализовано разграничение прав доступа на уровне пользовательских сессий для трёх системных ролей:

| Роль | Пароль для входа | Доступные модули |
| :--- | :---: | :--- |
| **Администратор (Директор)** (`admin`) | `1` | Полный доступ ко всем разделам, отчётам и аналитике |
| **Менеджер** (`manager`) | `2` | Свободные номера, база гостей, бронирование, заселение и выселение |
| **Бухгалтер** (`accountant`) | `3` | Финансы, выставленные счета, регистрация платежей, расчёт зарплаты |

## Инструкция по запуску

### 1. Настройка базы данных PostgreSQL
1. Создайте пустую базу данных с именем `hotel_eleon` в `pgAdmin 4` или через терминал `psql`.
2. Последовательно выполните SQL-скрипты в Query Tool:
   * `schema.sql` — создание структуры таблиц и индексов;
   * `views_and_functions.sql` — создание представлений и хранимых функций;
   * `seed.sql` — загрузка тестовых записей.
3. При необходимости обновите параметры подключения (`DB_USER`, `DB_PASS`) в начале файла `app.py`.

### 2. Установка зависимостей и запуск сервера
```bash
# Установка необходимых библиотек
pip install flask psycopg2-binary

# Запуск веб-приложения
python app.py
```

После запуска приложение будет доступно в браузере по адресу: **`http://127.0.0.1:5000`
